# Project Overview & Mission

## Goal
Cure "doom scrolling" by replacing mindless content with AI-driven personalized knowledge cards.

## Core UI
A vertical, full-screen scrolling feed where each card is an interactive learning session.

---

# Dual-Agent Architecture (Strict Separation)
ScrollSmart utilizes a rigorous dual-agent system. The boundaries between these agents must never be crossed.

## Agent 1 (Content Generator)
- **Location:** `backend/app/agents/agent1_content.py`
- **Role:** Creative science communicator. Generates "hooks" and manages chat interactions.
- **Constraints:** 
  - Must NEVER access raw user profile data or weights.
  - Only receives a natural language summary generated by Agent 2.

## Agent 2 (Analyst)
- **Location:** `backend/app/agents/agent2_analyst.py`
- **Role:** Behavioral analyst. Updates interest weights and selects the next topics.
- **Constraints:**
  - Must focus entirely on logic, calculation, and statistics.
  - Does NOT generate UI content, chat responses, or hooks.
